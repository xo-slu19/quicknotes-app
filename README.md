# QuickNotes

QuickNotes is a simple, responsive note-taking web application built with HTML, CSS and JavaScript. It allows users to create notes, organize them into Personal, Work and Study categories, search saved notes, and delete individual notes. Notes are saved in the browser using localStorage, so they remain available after refreshing the page.

## Features

- Add notes with a text description.
- Organize notes into Personal, Work and Study categories.
- Display the date and time each note was created.
- Delete individual notes.
- Search notes using case-insensitive text matching.
- Validate empty notes and notes longer than 200 characters.
- Display the total number of notes.
- Save notes in localStorage.
- Responsive layout for desktop and mobile screens.
- Clear all notes with a confirmation prompt.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage
